Bonus Thinking Question:
If the array was already sorted {6, 15, 29, 38, 42} — how many swaps would Bubble Sort do? Why?
Ans : It would take 0 swaps as Bubble sort only triggers  a swap when a left element is greater  than its adjacent right element. 
Since the array is in perfect ascending order there is no need of bubble sort
